Standalone puzzle projects, each with its own rules page and a playable build.

Projects

  • Sudoku Puzzle — classic 9×9 Sudoku plus the Kropki variant, where dot markers between cells tell you whether the neighbouring digits are consecutive or in a 1:2 ratio. Play the full version as a Sudoku game in your browser, with a new grid published every day.
  • 24 Points Game — four numbers on the board, combine them with + − × ÷ so every hand totals exactly 24. Short rounds, no timer, good for warming up mental arithmetic. Try the 24 points game online when you only have a couple of minutes.

Puzzle Solvers

Seventeen solvers for the puzzles people actually get stuck on. None of them just print an answer and walk away: each returns the thing you were missing — the move sequence, the cells to delete, the square that was forcing a contradiction — so you can see why the solution works and finish the next grid yourself. All free, no sign-up, and they run in an ordinary browser tab.

Sudoku & grid logic

  • Sudoku Solver — number placement. Returns the completed grid, and tells you which of your own entries was already wrong before it started.
  • Killer Sudoku Solver — number placement with cages. Fills the grid and names the cage whose sum could not be met.
  • Futoshiki Solver — inequality grid. Fills the grid and points at the < and > signs that contradict your entries.
  • Kakuro Solver — cross sums. Fills the grid, which helps once a run has collected too many candidates to pencil in.
  • KenKen Solver — cage arithmetic (Calcudoku). Fills the grid and flags the cage targets that clash with your draft.
  • Skyscraper Solver — visibility clues. Fills the grid when the edge clues still leave several arrangements standing.
  • Takuzu Solver — binary logic (Binairo). Breaks the deadlock when the colour-balance and no-three-in-a-row rules collide.

Arithmetic & number targets

  • 24 Game Solver — arithmetic. Lists every valid expression, which also settles whether a hand has a solution at all.
  • Make 10 Solver — arithmetic. Returns all the routes to 10 rather than a single one, so you can compare them.
  • Sumplete Solver — deletion sums. Tells you exactly which cells to delete when row and column targets cannot both be met by hand.
  • Mulplete Solver — deletion products. The same idea with multiplication, for when product targets conflict.

Sliding & toggle puzzles

  • Sliding Puzzle Solver — tile sliding, 3×3 up to 9×9. Returns the minimum move sequence, so you get the optimal path out of a half-solved board rather than a longer one.
  • Klotski Solver — sliding blocks (Huarong Dao). Returns a step-by-step move plan for when the large block is boxed in.
  • Lights Out Solver — toggle logic. Returns the minimal set of toggles that reaches all-off, and can say when a board is unsolvable from the position given.

Deduction & words

  • Wordle Solver — word deduction. Narrows the official answer list to the words still possible and ranks the next guess by how much it splits what is left. Letters ruled out stay ruled out.
  • wordle hint today — spoiler-safe daily clues. Each hint is revealed one at a time, from a vague definition down to the starting letter, so you can stop the moment you have enough. The practice board lets you try the guess before you look anything up.
  • wordle answer today — the daily Wordle answer, updated every day. If a hint got you close but the last guess is still uncertain, this is where the confirmed solution lives, with the full past-answer archive for checking streaks and avoiding repeats.
  • Mastermind Solver — deduction, also good for Bulls and Cows. Returns the candidate list plus the guess that eliminates the most of it.
  • Matchstick Equation Solver — matchstick rearrangement. Names the exact sticks to move when a limited number of moves has to turn a wrong equation into a right one.
